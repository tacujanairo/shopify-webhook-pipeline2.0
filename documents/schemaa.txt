The Realistic 4-Table Architecture

Instead of dumping everything into an orders table, split your database into four distinct tables. This layout prevents data duplication and unlocks powerful reporting.

 [ Customers ] ───< [ Orders ] ───< [ Line Items ] >─── [ Products ]

1. Customers Table

Instead of rewriting the customer's name and email every single time they buy something, give them a permanent profile.

    Fields:

        Customer ID (Primary - Formula or Shopify Customer ID string)

        First Name / Last Name / Email / Phone

        Orders (Link to Orders Table)

        Lifetime Value (LTV) (Rollup field summing Total Price from the Orders table)

2. Orders Table

This becomes a clean ledger of financial transactions. It no longer holds product titles or repeated customer details.

    Fields:

        Order ID (Primary - Shopify Order Name/ID like #1001)

        Customer (Link to Customers Table — replaces raw text name/email)

        Order Date (Date/Time)

        Financial Status (paid, refunded, partially_refunded)

        Fulfillment Status (unfulfilled, fulfilled, partial)

        Line Items (Link to Line Items Table)

        Total Price (Currency)

3. Line Items Table (The Secret Sauce)

This is the junction table that connects an order to the specific products inside it. If a customer buys 3 items, Shopify sends them in one webhook, but Airtable should create 3 rows here.

    Fields:

        Line Item ID (Primary - Autonumber or string formula like Order ID + Product SKU)

        Order Link (Link to Orders Table)

        Product Link (Link to Products Table)

        Quantity (Number)

        Price Per Unit (Currency)

        Total Line Price (Formula: Quantity * Price Per Unit)

4. Products Table

A master catalog of what you sell. This lets you track which items are your best sellers.

    Fields:

        SKU / Variant ID (Primary)

        Product Title / Variant Title

        Unit Cost (What you paid for it - helps track profit margins)

        Line Items (Link to Line Items Table)

        Total Units Sold (Rollup field summing Quantity from Line Items)
